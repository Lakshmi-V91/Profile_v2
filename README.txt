Put your images in this folder, then update the matching path in index.html:

- profile.jpg        -> hero photo (replaces .hero__photo-placeholder)
- intro-graphic.jpg   -> introduction section image/illustration
- hobby-1.jpg, hobby-2.jpg, hobby-3.jpg -> hobby tile images
- favicon.svg (already here) -> browser tab icon, swap for your own anytime

Any reasonable image format works (jpg, png, webp, svg). Keep hero and
intro images roughly square/portrait for the best fit with the
placeholder shapes already sized in style.css.
